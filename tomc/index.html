TOMC Memory

Context compression and task memory for AI assistants.

TOMC Memory is an open-source tool built on Task-Oriented Memory Compilation. Give it a history, the next task and a memory budget. It selects source text and computes supported state, relation or count records to prepare context for that task. Preparation runs on CPU, with no training or extra model service.

Use the Python API in your application, or save and recall project notes through an MCP server in assistants such as Codex and Claude Code.

Two ways to use TOMC

Prepare context before an API call

Your application sends the prepared context in place of the original history, while preserving its instructions and protocol. The reader model stays the same. Inspect the selected evidence and check answer quality on your own tasks before choosing a smaller budget.

Follow the Python API guide →

Resume a project from saved notes

Explicitly save a brief, decisions, constraints and unfinished work with remember_memory, then prepare those notes for the next task with recall_memory. Assistants on the same computer can reuse notes when their TOMC servers open the same local database.

Try a Codex → Claude Code → Codex handoff →

TOMC is a research preview. Savings depend on the history, task and budget. The assistant host manages its active chat; use TOMC with separately supplied history or explicitly saved notes. See the documentation for client support, integration behavior and current limitations.

Research, source and releases
