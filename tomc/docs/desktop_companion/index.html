TOMC desktop companion (beta)

中文速查 · macOS details · Install the assistant plugins

The desktop companion is a small cat on your screen. It shows how many tokens TOMC has saved, what they are worth at each model's listed input price, and which conversations they came from. It also keeps the contexts TOMC prepared, organized by your original conversation names, so you can copy a continuation prompt for another assistant or move a context to another computer.

On Windows you can also turn on automatic request processing: a local gateway that compresses eligible old history in Codex and Claude Code requests before they leave your computer. Without the gateway, the cat counts savings from TOMC's own tools (prepare_context, recall_memory).

Install on Windows

You need Windows 10 or 11, Python 3.10 or newer (python.org or the Microsoft Store) and this repository:

git clone https://github.com/ZipengWu365/TOMC.git
cd TOMC
py scripts\install_windows_companion.py

The first command only shows the plan; nothing changes. Then install the cat:

py scripts\install_windows_companion.py --install

or the cat plus automatic request processing:

py scripts\install_windows_companion.py --install --gateway

The installer:

  • creates a private Python environment for the cat in %USERPROFILE%\.codex\tomc and downloads Qt (PySide6-Essentials) into it;
  • copies TOMC from this checkout, so the cat keeps working if you move or delete the checkout;
  • adds TOMC to the Start menu and starts the cat at Windows sign-in;
  • starts the cat in the bottom-right corner of the screen.

With --gateway it also creates the gateway's own environment, starts it at sign-in (hidden), waits until it answers on 127.0.0.1:43187, and only then points Codex (openai_base_url in .codex\config.toml) and Claude Code (ANTHROPIC_BASE_URL in .claude\settings.json) at it. Your sign-in, models and other settings are kept, and exact copies of both files are saved first. Quit and reopen Codex and Claude Code afterwards so new requests use the gateway.

Gateway requirements and choices:

  • Codex must be signed in with ChatGPT; API-key Codex setups are not supported by the gateway yet. Open Codex once before installing so .codex\config.toml exists.
  • --hosts claude (or --hosts codex) routes only one assistant.
  • If Codex or Claude Code already uses a custom endpoint, another model provider or a Codex profile, the installer says so and changes nothing.

The command prints a receipt path. Keep it: it is how you undo the installation.

Install on macOS

Follow Desktop companion beta: macOS. It builds a local TOMC.app from this checkout; automatic request processing is not available on macOS yet.

Using the cat

  • Click the cat to see tokens saved, money saved per model and the last 14 days. Choose today, the last seven days or all time.
  • Analysis › opens a report: savings per conversation and per kind of work, a ranked table, how requests were handled, how much each compression removed, context lengths and 30 days of savings.
  • All records › opens the context library: your conversations under their original names, each saved context with copy, export, rename and delete, and import of a package from another computer.
  • Right-click the cat for the menu. To quit, hover over the cat and click the × on its head, or choose Quit TOMC. Closing other windows never quits the cat; it restarts at sign-in.

The cat grows through four stages with the length of the contexts it has compressed.

What to expect

Savings appear only for requests TOMC actually shortens. Codex and Claude Code manage much of their context themselves, short histories already fit, and some content formats are not supported yet; those requests pass through unchanged, and the analysis report shows how many of each there were. Long working sessions benefit most. Amounts are the tokens removed, valued at each model's listed input price.

Your data and privacy

  • Statistics, saved contexts and settings stay in %USERPROFILE%\.tomc\memory.sqlite3 (~/.tomc on macOS). Turn off context recording, or TOMC for one conversation, in All records › Settings and connections.
  • The gateway listens on 127.0.0.1 only. Request bodies and sign-in headers are forwarded in memory and never written to disk.
  • Send anonymous feedback in the analysis report shows the complete report first. It contains kinds of work (coding, writing, papers …) and numbers only: no conversation names, content, folders or IDs. It is submitted only when you confirm it on GitHub, as a public pull request under your account. See feedback/README.md.

Update and uninstall (Windows)

To update the cat, update the checkout (git pull) and run the installer again with --install. The previous copy is kept in %USERPROFILE%\.codex\tomc\archive. An existing gateway is updated with py scripts\patch_gateway_runtime.py --runtime <gateway folder> (preview first, then --install).

To uninstall:

py scripts\install_windows_companion.py --uninstall "<receipt path>"

This restores the Codex and Claude Code settings it changed, stops the cat and the gateway, and removes the shortcuts and the programs it installed. If you have edited those settings since, it stops and says so instead of overwriting your changes. Your data in .tomc is kept. Receipts are under %USERPROFILE%\.codex\tomc\archive\windows-install-*.

Chinese quickstart

桌面小猫显示 TOMC 节省了多少 token、按各模型输入价值多少钱、来自哪些对话，并按原对话名整理压缩后的上下文，可以复制接续提示词交给别的 Agent，或导出到另一台电脑。Windows 上还可以开启自动请求处理：本机网关在请求发出前压缩 Codex 和 Claude Code 中符合条件的旧历史。macOS 暂不支持自动请求处理。

Windows 安装（需要 Python 3.10+ 和本仓库）：

git clone https://github.com/ZipengWu365/TOMC.git
cd TOMC
py scripts\install_windows_companion.py                      # 只预览，不做任何修改
py scripts\install_windows_companion.py --install            # 安装小猫
py scripts\install_windows_companion.py --install --gateway  # 小猫 + 自动请求处理

开启自动请求处理后，退出并重新打开 Codex 和 Claude Code。Codex 需要用 ChatGPT 登录（暂不支持 API key 方式）；--hosts claude 只接入 Claude Code。安装会打印回执路径，卸载时用：

py scripts\install_windows_companion.py --uninstall "<回执路径>"

卸载会恢复它改过的 Codex / Claude Code 设置、移除快捷方式和安装的程序，保留 .tomc 里的数据；如果之后你手动改过这些设置，它会停下来说明，不覆盖你的修改。macOS 安装见 macOS 说明。

使用：点小猫看节省的 token 和钱；「分析报告 ›」看各对话和工作类型的节省；「全部记录 ›」管理上下文。退出请把鼠标移到小猫上，点猫头上的 ×，或右键选「退出 TOMC」；关闭其他窗口不会退出小猫。数据都保存在本机；「匿名提交反馈」只提交工作类型和数字，提交前会先给你看完整内容。
