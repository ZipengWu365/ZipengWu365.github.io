Research program

Temporal representations as the common object

My work treats temporal representation as the central problem. Decomposition, forecasting, classification, symbolic regression, similarity search, retrieval, and rollout diagnostics are downstream tests of whether a representation preserves useful temporal structure.

Foundation / World Models

Temporal representation for foundation and world models, including action histories, temporal memory, VLA trajectories, computer-use sequences, state/action histories, and long-horizon model rollouts.

Time-Series ML

Representation learning under non-stationarity, including decomposition as representation extraction, stationarity-aware retrieval, forecasting diagnostics, and robust evaluation of noisy signals.

Research Software

Open software for decomposition and similarity: stable interfaces, inspectable temporal components, HTML reports, JSON outputs, and reproducible evaluation workflows.
