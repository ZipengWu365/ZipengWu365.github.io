All 31 Method Animations

Choose a method to see its calculation unfold in four steps. Each page includes a Play animation control, a static diagram, parameter explanations, references, and downloadable numerical arrays with source provenance. Playback starts only when requested; the written steps remain available without JavaScript.

The gallery covers 31 registered entries: 8 smoothing, seasonal and subspace entries, 7 adaptive or time-frequency entries, and 16 experimental decomposition blocks. Autoformer and DLinear are aliases of the moving-average block. The count includes these aliases and does not imply 31 independent algorithms.

Read the scope labels

Label Meaning in DeTime
maintained A maintained core implementation with Python and native execution paths.
stable A retained method or wrapper on the supported interface.
optional-backend Requires an additional upstream package, such as PySDKit.
experimental A research operator or illustration with the limits stated on its page.

These labels describe the package support level. The synthetic teaching examples show computations; they do not measure forecasting accuracy or establish clinical or financial performance. Experimental architecture names refer to the implemented decomposition blocks. N-BEATS uses explicitly chosen, untrained coefficients in its animation. The Gabor example uses a fixed teaching codebook.

Method Computation illustrated Scope

STDR Partition and center cycles → Separate dispersion and shape → Average shapes across cycles → Compute the common result maintained
STL Form seasonal-phase subseries → Use local polynomial smoothing → Alternate seasonal and trend → Form the additive result stable
