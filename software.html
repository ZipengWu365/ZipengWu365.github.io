DeTime: Time-Series Decomposition in Python

DeTime (also written De-Time) is an open-source Python toolkit and CLI for extracting trend, seasonal or oscillatory components, and residuals from univariate and multichannel time series. It provides a shared interface for SSA, MSSA, STL, VMD, EMD, wavelets, and other decomposition methods. Install the package as detime-toolkit and import it as detime.

DeTime documentation and examples · Source code on GitHub · Install from PyPI
